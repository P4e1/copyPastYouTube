# presentation

Роутеры FastAPI, DTO Pydantic и зависимости текущего пользователя. Swagger `/docs` строится из этих DTO.

Можно импортировать сценарии `application` и переводить доменную ошибку в статус ответа.

Нельзя импортировать сессию SQLAlchemy, клиент MinIO и писать SQL. В базу и хранилище этот слой не ходит.
