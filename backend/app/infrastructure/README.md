# infrastructure

Реализации портов домена: модели SQLAlchemy, репозитории, Alembic, клиент MinIO, воркер ffmpeg, хеш паролей, выпуск JWT.

Можно импортировать `domain` и реализовывать его порты. Сборка зависимостей для сценариев живёт здесь.

Нельзя импортировать роутеры `presentation` и отвечать на HTTP из этого слоя.
