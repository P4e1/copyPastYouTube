# application

Сценарии: регистрация, логин, видео, лента, поиск, просмотр, лайк, комментарий, подписка, плейлист, жалоба, скрытие, смена роли.

Можно импортировать `domain` и вызывать его порты.

Нельзя импортировать FastAPI и SQLAlchemy, собирать HTTP-ответ и знать коды статусов. Сценарий возвращает результат или доменную ошибку.
