# Фронтенд

Интерфейс — максимально близкая копия YouTube, а не список карточек и не админка. Ориентир — расположение блоков и поведение сайта YouTube. Стек: React + Vite. Тема как у открытого YouTube: белый фон, чёрные залитые иконки, красный знак логотипа, поиск-«таблетка» и синяя кнопка «Войти».

Каркас, главная, просмотр и поиск уже собраны. Вход сохраняет JWT в `localStorage`. Пустая лента пишет «Смотреть пока нечего». Пустой запрос поиска просит ввести текст, запрос без роликов пишет «Ничего не найдено». Полная шапка канала, загрузка и модерация подключаются следующими срезами. Поведение экранов — в [docs/ui.md](../docs/ui.md).

## Запуск

Из каталога `frontend`, при работающем API:

```bash
npm install
npm run dev
```

Dev-сервер открывается на `http://127.0.0.1:5173`. Базовый адрес API берётся из `VITE_API_BASE` (образец — [.env.example](.env.example), по умолчанию `http://127.0.0.1:8000`). Этот адрес должен быть в `CORS_ORIGINS` бэкенда.

## Каркас

Шапка, левая колонка и область контента.

- В шапке слева направо: логотип, кнопка меню, строка поиска по центру, «Создать», колокол без реальных уведомлений, аватар.
- В колонке: «Главная», «Подписки», «Вы».
- На узком окне колонка становится выезжающим меню. Лента остаётся сеткой, шапка не разваливается на две строки с поиском поверх карточек.

Вход и регистрация показывают только форму, без колонки и без пунктов ленты.

## Экраны

**Главная.** Сетка превью. На карточке длительность поверх превью, аватар канала, название в две строки, имя канала, число просмотров и дата. Клик открывает просмотр.

**Просмотр.** Крупный плеер на нативном `video`. Адрес ролика приходит с API после проверки прав. Под плеером название, счётчик просмотров, лайк и дизлайк с числами, кнопка «Поделиться» как визуальный элемент. Рядом канал и красная «Подписаться». Описание сворачивается. Ниже комментарии: аватар, текст и поле ввода.

**Канал.** Обложка, аватар, имя, число подписчиков, «Подписаться», вкладки «Видео» и «Плейлисты».

**Поиск.** Строка в шапке ведёт на выдачу. Результат — список: превью слева, название, канал и описание справа.

**Загрузка.** Шаги как в Творческой студии. Сначала выбор файла и полоса прогресса прямой отправки в хранилище. Затем название, описание и видимость: «Открытый доступ», «Доступ по ссылке», «Ограниченный доступ» со списком пользователей.

**Вход и регистрация.** Отдельные формы в том же цвете и шрифтовом ритме, что и остальной интерфейс.

**Модерация.** Список жалоб и действие «Скрыть». Пункт меню виден модератору и администратору. Обычный пользователь пункт не видит, прямой адрес отвечает отказом.

## Состояния

- Пустая лента — спокойный пустой экран с текстом, что видео пока нет. Сетка не заменяется ошибкой.
- Пустой поиск и пустой запрос — отдельные экраны, страница не выглядит сломанной.
- Скрытое модератором видео зритель не открывает. Владелец видит свою карточку с пометкой, что ролик скрыт.
- Прогресс загрузки — непрерывная полоса от 0 до 100 по ходу отправки файла в хранилище. До завершения метаданные следующего шага не сохраняют ролик как готовый к просмотру.
