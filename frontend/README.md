# Фронтенд

Интерфейс — максимально близкая копия YouTube, а не список карточек и не админка. Ориентир — расположение блоков и поведение сайта YouTube. Стек: React + Vite. Тема как у открытого YouTube: белый фон, чёрные залитые иконки, красный знак логотипа, поиск-«таблетка» и синяя кнопка «Войти».

Каркас, главная, просмотр, поиск, страница канала, загрузка и модерация уже собраны. Вход сохраняет JWT в `localStorage`. Пустая лента пишет «Смотреть пока нечего». Пустой запрос поиска просит ввести текст, запрос без роликов пишет «Ничего не найдено». На канале вкладка «Видео» показывает ту же карточку, что главная, вкладка «Плейлисты» — название и ролики по порядку. Скрытый ролик владельца помечен «Скрыто». Поведение экранов — в [docs/ui.md](../docs/ui.md).

## Запуск

Из каталога `frontend`, при работающем API:

```bash
npm install
npm run dev
```

Dev-сервер открывается на `http://127.0.0.1:5173`. Базовый адрес API берётся из `VITE_API_BASE` (образец — [.env.example](.env.example), по умолчанию `http://127.0.0.1:8000`). Этот адрес должен быть в `CORS_ORIGINS` бэкенда. В контейнере сборка ходит на `/api` того же адреса, что и страница: `POST /api/auth/login` становится `POST /auth/login` у контейнера API. Nginx резолвит имя `api` при каждом запросе и только по IPv4, иначе после старта отвечает 502 при живом API.

## Каркас

Шапка, левая колонка и область контента.

- В шапке слева направо: логотип, кнопка меню, строка поиска по центру, «Создать», колокол без реальных уведомлений, аватар. У вошедшего «Создать» открывает меню с пунктом «Добавить видео». Гость с этой кнопки попадает на вход.
- В колонке: «Главная», «Подписки», «Вы».
- На узком окне колонка становится выезжающим меню. Лента остаётся сеткой, шапка не разваливается на две строки с поиском поверх карточек.

Вход и регистрация показывают только форму, без колонки и без пунктов ленты.

## Экраны

**Главная.** Сетка превью. На карточке длительность поверх превью, аватар канала, название в две строки, имя канала, короткое число просмотров и срок («2 ч назад»). Клик открывает просмотр.

**Просмотр.** Крупный плеер на нативном `video`. Адрес ролика приходит с API после проверки прав. Под плеером, как на YouTube: название, канал с чёрной «Подписаться» (после подписки — колокол), лайк с числом, дизлайк без числа, «Поделиться» (копирует ссылку), «Добавить в плейлист» и «Ещё» с жалобой. Описание — серая плашка с просмотрами и сроком. Справа или ниже — рекомендации с чипами «Все видео», «С этого канала» и «Недавно опубликованные». Комментарии читает и гость; писать можно после входа.

**Канал.** Обложка, аватар, имя, число подписчиков и чёрная «Подписаться». Вкладки «Видео» и «Плейлисты». Видео — карточка главной; у скрытого ролика владельца метка «Скрыто». Плейлист показывает название и ролики в сохранённом порядке. Владелец на этой же странице задаёт название плейлиста и добавляет свой видимый ролик.

**Поиск.** Строка в шапке ведёт на выдачу. Результат — список: превью с длительностью слева, справа название, канал, просмотры, срок и описание.

**Загрузка.** Два шага. Сначала выбор mp4: файл уходит напрямую в хранилище, полоса прогресса растёт от 0 до 100, и следующий шаг не завершает ролик, пока отправка не дошла до конца. Затем название, описание и видимость: «Открытый доступ», «Доступ по ссылке», «Ограниченный доступ» со списком пользователей. Сохранение ставит ролик в обработку; когда он готов, карточка ведёт на просмотр.

**Вход и регистрация.** Отдельные формы в том же цвете и шрифтовом ритме, что и остальной интерфейс.

**Модерация.** Пункт «Модерация» в колонке есть только у модератора и администратора. На странице открытые жалобы: название ролика, причина, имя пожаловавшегося и кнопка «Скрыть». После скрытия строка уходит из списка. Обычный пользователь пункт не видит, а прямой адрес пишет «Недостаточно прав» и не показывает жалобы. Жалобу со страницы просмотра отправляет любой вошедший зритель, которому ролик доступен.

## Состояния

- Пустая лента — спокойный пустой экран с текстом, что видео пока нет. Сетка не заменяется ошибкой.
- Пустой поиск и пустой запрос — отдельные экраны, страница не выглядит сломанной.
- Скрытое модератором видео зритель не открывает. Владелец видит свою карточку с пометкой, что ролик скрыт.
- Прогресс загрузки — непрерывная полоса от 0 до 100 по ходу отправки файла в хранилище. До завершения метаданные следующего шага не сохраняют ролик как готовый к просмотру.
