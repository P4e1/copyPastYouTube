# Каталоги фронта

React + Vite лежат в этом каталоге. Каркас, вход и регистрация уже собраны. Остальные экраны из списка ниже ещё без ленты, плеера и загрузки.

## pages

- `HomePage` — главная, сетка превью.
- `WatchPage` — просмотр: плеер, лайки, описание, комментарии.
- `ChannelPage` — канал: обложка, вкладки «Видео» и «Плейлисты», подписка.
- `SearchPage` — результаты поиска списком.
- `UploadPage` — шаги загрузки: файл, прогресс, метаданные, видимость.
- `LoginPage` и `RegisterPage` — вход и регистрация без бокового меню.
- `ModerationPage` — жалобы и скрытие видео. Пункт виден модератору и администратору.

## components

Каркас `AppShell` (шапка и левая колонка), карточка видео, плеер, список комментариев, кнопка подписки.

## api

Клиент REST к бэкенду. Адреса совпадают с маршрутами из `backend/app/main.py`. Прямая отправка файла идёт в presigned URL хранилища, не через этот клиент.
